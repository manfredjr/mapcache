# MapCache - MT

Mapa e limpeza de cache para Windows 10 e 11, da MT - Manfred Tecnologia. Mostra quanto espaço cada tipo de arquivo descartável ocupa, em todos os perfis da máquina, e limpa só o que você marcar e confirmar.

Este repositório guarda só as versões do programa, para baixar. O código é fechado.

- Site e manual: https://mapcache.manfred.com.br/
- Baixar a última versão: https://github.com/manfredjr/mapcache/releases/latest/download/mapcache.exe

O programa é gratuito, sob a licença de uso da MT, que acompanha cada versão.
